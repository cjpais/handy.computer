## Overview

The CLI is primarily for **Linux users**, especially those using tiling window managers or Wayland compositors where global keyboard shortcuts don't always work natively. On macOS and Windows, the GUI handles everything and you generally don't need the command line.

Handy can be launched from the command line with flags to customize its behavior. This is useful for scripting, automation, and window manager integration.

## Flags

```bash
handy [OPTIONS]
```

| Flag | Description |
|------|-------------|
| `--start-hidden` | Start with the main window hidden |
| `--no-tray` | Disable the system tray icon |
| `--toggle-transcription` | Toggle transcription on/off in a running instance |
| `--toggle-post-process` | Toggle transcription with post-processing on/off |
| `--cancel` | Cancel the current operation in a running instance |
| `--debug` | Enable debug mode with verbose logging |

The `--toggle-transcription` and `--toggle-post-process` flags communicate with an already-running Handy instance. If Handy is recording, it stops and transcribes. If idle, it starts recording. This is useful for binding to window manager shortcuts.

## Signal Control

On macOS and Linux, you can also control a running Handy instance using Unix signals:

| Signal | Action |
|--------|--------|
| `SIGUSR2` | Toggle transcription (start/stop recording) |
| `SIGUSR1` | Toggle transcription with post-processing (macOS only) |

```bash
# Toggle transcription
pkill -USR2 -x handy
```

**On Linux, don't send `SIGUSR1`.** Handy no longer listens for it there, because WebKitGTK uses it internally, and sending it can crash the app. Use `handy --toggle-post-process` instead, and remove any `pkill -USR1` bindings you have.

On Wayland, where Handy's own shortcut often only works while its window is in front, bind `handy --toggle-transcription` to a shortcut in your desktop or compositor. See [Linux Setup](/docs/linux).

## Scripting

You can use Handy in scripts to capture speech-to-text output. This is especially useful for automation workflows.

## Window Manager Integration

Handy works well with tiling window managers and custom keybinding setups. Use either CLI flags or signals to control Handy from your compositor.

### Hyprland

```bash
# Using CLI flags
bind = $mainMod SHIFT, period, exec, handy --toggle-transcription

# Using signals
bind = $mainMod SHIFT, period, exec, pkill -USR2 -x handy
```

### sway / i3

```bash
# Using CLI flags
bindsym $mod+Shift+period exec handy --toggle-transcription

# Using signals
bindsym $mod+Shift+period exec pkill -USR2 -x handy
```

### GNOME (Wayland)

GNOME on Wayland doesn't support global shortcuts from third-party apps. Add a custom shortcut instead:

1. Open **Settings > Keyboard > View and Customize Shortcuts > Custom Shortcuts**
2. Add a new shortcut with the command: `handy --toggle-transcription`
3. Assign your preferred key combination
